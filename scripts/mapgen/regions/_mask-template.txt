# ═══════════════════════════════════════════════════════════════════════
#  海陆掩码模板（给 build-map.lua 的 [terrain] mode=mask 用）
#  ----------------------------------------------------------------------
#  一个字符 ≈ 一格，掩码**覆盖整张地图**，按归一化位置铺开。
#
#  X = 陆地        . = 海（其实"既不是 X 也不是 -"的字符都当海，空格也是海）
#  - = 保留原样，这一格不动（不想让脚本碰的地方，比如已画好的内陆湖/河）
#  # 或 ; 开头 = 注释行（不会参与绘图）
#
#  怎么画：
#    1. 行数×列数的比例要接近你的地图（本示例 48×24 = 2:1，对应 400×200 的地图）；
#       比例差太多脚本会在报表里警告，地形会被拉伸
#    2. 先用大块 X 铺出大陆，再用 . 抠出海湾、海峡、湖泊；最后点几个 X 当岛屿
#    3. 配合 [projection] 的经纬度窗口来想形状：掩码左上角 = (lon_west, lat_north)
#    4. 开 smooth = 1 会做一次 3×3 多数表决，把孤零零的 1 格去掉，海岸线更自然
#
#  下面这张是**格式示例**（不是真实地理），照它的密度改画成你要的地区即可。
# ═══════════════════════════════════════════════════════════════════════
